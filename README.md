# CareerCraft · 生涯之书

Minecraft **服务端插件**（不是模组，玩家无需安装任何东西）。
按玩家在服务器里的进度，自动发放「生涯成就」并给奖励；成就与奖励都可以在 **Web 管理面板**里改，改完即时生效。

- 服务端：**Purpur 26.3**（Paper 下游分支，插件生态通用）
- 插件 API：**Paper API 26.3**，Java **21**
- 存储：SQLite（单文件，备份就是拷一个文件）

---

## 它在做什么

1. **听**：服务器广播「玩家完成了什么」——原版进度（advancement）、原版统计（statistic），以及插件自己算的自定义条件
2. **判**：命中某条成就的条件，且该玩家没拿过 → 记录 + 触发奖励
3. **发**：物品 / 经验 / 执行命令（可发权限、点券、传送）/ 经济（需 Vault）

每条成就**每人只发一次**；玩家离线时命中的，上线后补发。

## Web 控制台

插件内置一个网页控制台（默认 `:8123`），浏览器打开即可：

- 账号密码登录（bcrypt），两种角色：**只读 / 可编辑**
- 成就的增删改查：名称、描述、图标、判定条件、奖励、启用开关
- 保存后几秒内生效，**不需要重启服务器**

> 安全约定：默认只绑内网，不对公网开放端口；对外访问走 Caddy/Nginx 反向代理 + HTTPS。

## 目录规划

```
src/main/java/com/xiangqin/careercraft/
├── CareerCraftPlugin.java     插件入口
├── command/                   游戏内命令（/cc ...）
├── achievement/               成就定义、条件判定、触发与发奖
├── storage/                   SQLite 存取
├── listener/                  进度 / 统计 事件监听
└── web/                       内嵌 HTTP 控制台（静态页 + API）
src/main/resources/
├── plugin.yml
├── config.yml
└── web/                       前端页面
```

## 开发计划

- **P0** 骨架：插件可加载、`/cc` 有响应、控制台可打开
- **P1** 成就引擎：接原版进度 + 统计，示例成就，发奖 + 防重复
- **P2** 控制台：登录、成就列表、改奖励、保存生效
- **P3** 打磨：离线补发、导入导出、日志、角色权限

## 构建

需要 JDK 21 + Maven：

```bash
mvn clean package
```

产物：`target/CareerCraft-<version>.jar` → 丢进 `plugins/` 重启服务器。
